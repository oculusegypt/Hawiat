## 2. الهيكلية ومكونات النظام المحدثة

### أ. كروت وباقات الخدمات (12 فئة مستقلة)
- **تنظيف الشقق السكنية**: عدادات الغرف والحمامات والمطابخ.
- **تنظيف الفلل والقصور**: خيارات الفلل الصغيرة، الدوبلكس، القصور والأدوار.
- **غسيل وتطهير المجالس بالبخار**: أطقم المجالس، الكنب، وأمتار السجاد (م²).
- **جلي وتلميع الرخام والبلاط**: مساحة جلي وتلميع الأرضيات (م²).
- **تنظيف وتطهير خزانات المياه**: خزان أرضي / علوي / خزانين.
- **غسيل وتنظيف مكيفات الهواء**: عدادات أجهزة السبلت، الشباك، والمخفي.
- **مكافحة وإبادة الحشرات والرش**: خيارات الصراصير، بق الفراش، والنمل الأبيض.
- **تنظيف بعد البناء والتشطيب**: مساحة العقار وإزالة الإسمنت والدهانات.
- **تنظيف واجهات المباني والمكاتب**: نوع الواجهة وعدد الأدوار.
- **تنظيف المساجد والمدارس والمنشآت**: خيارات المرافق العامة.
